Tinkering

Around the house

  • labs.nilleb.co — an ESP32-S3 e-ink voice assistant that writes notes to my vault, plus 3D-printing notes.
  • Matins — a morning newspaper for e-readers, composed from my read-later queue and RSS feeds, served over OPDS.
  • Jean Carmet — the week's shows at our local theatre-cinema, rebuilt every Monday from the venue's PDFs.
  • family.nilleb.io — a family tree viewer for any Gramps file: load an export, get an interactive hourglass chart.
  • trésor — a one-page, browser-only household treasury forecast.

On my Mac

  • tessera — a tiling window manager in Rust, because none of the others did Spaces right.
  • stts — local speech-to-text and text-to-speech, tuned for Apple Silicon.
  • omnisess — search every AI coding session (Claude Code, Codex, Cursor…) from one place.
  • localhost-router — https://app.localhost for every local port.
  • Window Switcher — a Raycast extension that lists the windows on the screen under the cursor, across Spaces.

In the browser

  • pagecast — a Raycast-style command palette for the page you're on; published as a Firefox/Zen add-on.

Agents & plumbing

  • varda — hands markdown tasks to AI agents and runs them in sandboxes.
  • switchboard — Signal, WhatsApp and Telegram behind one API, for bots that talk to the family.
  • proxium — an authentication proxy that injects API keys so agents never see them.
  • ics_normalizer — makes Outlook and Google Calendar agree on time zones.
