Pagecast privacy policy

last updated 8 November 2026 · applies to the Pagecast browser extension

Pagecast is a command palette for the page you are on. It has no server of its own, no account and no analytics: nothing you search for, click or type in Pagecast is sent to us or to any third party.

What Pagecast reads, and why

  • Page content. When you open the palette, Pagecast reads the current page's controls — their accessible names, roles, values and positions — so it can list them and click or focus the one you pick. This happens locally, on the page you are already looking at, and the result is discarded when the palette closes.
  • Open tabs. Pagecast asks the browser for the title, URL and favicon of your open tabs so it can list them and switch to the one you pick. This is held in memory while the palette is open and is never stored.
  • Clipboard. Only the Share current tab: copy URL command writes to the clipboard, and only when you run it.
  • Site commands. Some plugins offer commands specific to a site. Most read only what that site's own page already shows you. The Azure DevOps plugin additionally asks that organization for its repository list, with your existing browser session, so it can offer Open repository…: that request goes to the site you are on, never to us, and the list is used only to build the command menu.

What Pagecast does not do

  • It does not collect, store or send to us — or to any third party — personal data, browsing history, page content, form data, credentials, cookies or usage statistics. The only requests it ever makes go to the site you are already using, on your behalf, with your existing session.
  • It does not sell or share data with anyone, and it does not use data for advertising, profiling, creditworthiness or any purpose unrelated to the palette.
  • It does not load or execute remote code: all the code ships inside the extension package.
  • It has no third-party services, no telemetry endpoints and no user accounts.

Permissions

  • tabs — list open tabs so the palette can switch to them.
  • scripting — inject the palette into tabs that were already open when the extension was installed.
  • clipboardWrite — the copy-URL command.
  • Access to all sites — the palette must work on whatever page you are on, and cannot know that address in advance.

Data retention and removal

Pagecast keeps no data, so there is nothing to retain or delete. To remove the extension, uninstall it from your browser; nothing is left behind.

Changes

If a future version ever sends data anywhere, this policy will say so, and the extension will ask for your consent first. The current text always lives at this address.
