Pagecast

a command palette for the page you're on

Press ⌥. (Alt+Period) on any page and start typing: Pagecast fuzzy-searches everything you can act on, and runs it without the mouse.

What it searches

  • Page — every button, link, input and ARIA widget, named the way a screen reader names it, including the custom controls that link-hint extensions miss and elements inside open shadow roots.
  • Tabs — your open tabs, most recently used first.
  • Site commands — extra commands for the sites you use (Proton Mail, Microsoft Teams, Azure DevOps), plus a few everywhere: copy the current URL, open a preview as a full tab.

Prefixes narrow the search: > site commands, # page elements, @ tabs.

Install

Firefox / Zen — addons.mozilla.org

Chrome, Edge, Brave and Arc: not yet in the Chrome Web Store (submitted, in review). Firefox and Zen users can install it today.

Privacy

No server, no account, no analytics. Page content and tab titles are read locally when the palette opens and never leave the browser. Details in the privacy policy.
